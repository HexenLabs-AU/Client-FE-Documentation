Use reward codes to claim cash, delivery speed boosts, drivers, and event currency.

**All codes listed on this page are active. Each code can be redeemed once per player.**

## Redeem a code

1. Open **Settings**.
2. Find **Redeem Code** and enter the code in **Enter Code**.
3. Select **Redeem** and check the result shown in game.
